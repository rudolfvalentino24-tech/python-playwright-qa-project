QA TESTING PLAYGROUND

Purpose
-------
A local web application designed specifically for Playwright automation practice.

Demo login
----------
Username: tester
Password: password123

Run
---
1. Open a terminal in this folder.
2. Activate your existing virtual environment if you have one.
3. Install Flask:
   pip install -r requirements.txt
4. Start:
   python qa_playground.py
5. Open:
   http://127.0.0.1:3001

The app runs on port 3001 so it can run beside your Playwright Runner on port 3000.
